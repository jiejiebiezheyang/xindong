# Heartbeat (Xindong)

An exquisite web-based gacha simulation and earnings analysis tool designed to help you track pull history, analyze income, and perform simulated draws.

## ✨ Features

### 📊 Data Dashboard
- **Total Pulls** - Records cumulative draw counts
- **Total Spent** - Statistics on all currency consumed for pulls
- **Total Income** - Statistics on total earnings obtained from pulls
- **Profit/Loss Analysis** - Real-time calculation of the difference between earnings and spending

### 🎰 Gacha System
- **Pity Mechanism** - Comprehensive pity system design
- **Multiplier Selection** - Supports various gacha rate configurations
- **Pool Display** - Clear display of items in the reward pool

### 🎮 Simulation Features
- **Simulation Pulls** - Simulated pulling experience without consuming resources
- **Result Analysis** - Detailed data analysis of simulation results
- **Progress Tracking** - Visualized progress tracking during the simulation process

### 🎨 Interface Design
- **Responsive Layout** - Adapts to various screen sizes
- **Dark Theme** - Eye-friendly dark interface
- **Smooth Animations** - Comfortable interactive feedback

## 🚀 Quick Start

Simply open the `index.html` file directly in your browser to begin using it.

## 🎯 Usage Guide

1. **View Data** - The top panel displays core statistical metrics
2. **Configure Gacha** - Adjust rate settings via the sidebar
3. **Start Pulling** - Perform pull operations on the main panel
4. **View Pool** - View available rewards displayed at the bottom
5. **Simulation Mode** - Experience the fun of pulling without consumption

## 📝 Tech Stack

- Native HTML5/CSS3/JavaScript
- No backend dependency required
- Runs directly in the browser
